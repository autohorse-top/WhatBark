# 记忆路由协议（mem0 三段）

## 配置
- 共享池：`user_id="dev-orchestrator"`，`infer=False`（原文写入，防抽取失真）+ 写后回读验证一次。
- mem0 只承担**定向**职责：找回"教训/项目状态/既往决策"，不承担证据职责——引用记忆中的结论前必须核实工件本体。

## 三段协议
1. **开工检索**：任务开始时至少检索一次（关键词=技术栈+任务类型+项目名），命中条目评估后决定是否影响本轮策略。
2. **岔路口哨检**：重大技术决策（选型/架构/引入依赖）前检索"既往是否踩过"。
3. **收工写回**：每轮结束写一条（<=400字）：做了什么/关键决策与理由/踩的坑（含避免方式）/未竟事项。
   前缀固定 `[devteam][<项目/任务>]` 便于日后检索。

## 条目格式
[devteam][proj] <一句话主题>。（1）事实/决策；（2）教训/原因；（3）下次的先验动作。
