# 项目状态树规范

## 目的
跨会话、跨 agent 的单一事实源。任何人（或任何 agent）接手前读它，就知道战争打到哪了。

## 结构
**项目根的 `STATE.md`**（相对当前项目根解析——主团队目录用它就是团队自己的状态树；ocnew 派生项目用它就是该项目的状态树，互不串味），维护两节：
1. **任务板**：每个活跃任务一块（目标/当前状态/下一步/门禁状态）——状态用 `进行中/受阻/已完成/已放弃` 四值。
2. **变更日志**：倒序追加一行/事件（日期、agent、一句话）。禁删旧条目。

## 纪律
- 协调者每轮结束更新；其他 agent 通过委派回执驱动更新。
- 状态树与 mem0 分工：状态树=**现在进行时**的战场地图；mem0=**过去时**的教训沉淀。重叠时以状态树为准。
